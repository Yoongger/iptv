# IPTV频道管理与优化系统

## 项目概述
本项目是一个专业的IPTV频道管理工具，具备智能爬取、精准检测和自动优化功能。经过性能优化，解决了VLC测试阻塞和程序卡顿问题。

### 核心功能
- **智能频道爬取**：自动发现和收集IPTV频道源
- **精准可用性检测**：严格的流媒体验证，避免虚假可用率
- **智能排序优化**：支持自然数排序和中文拼音排序
- **自动M3U文件生成**：生成优化后的播放列表文件
- **稳定性测试系统**：从多个M3U文件中筛选最优稳定文件

### 技术亮点
- **多线程并发检测**：高效处理大量频道，避免阻塞
- **智能抽样测试**：平衡检测精度和性能，限制最大测试数量
- **VLC集成测试**：使用VLC播放器进行真实流媒体验证（带超时控制）
- **错误恢复机制**：自动处理网络异常和超时
- **智能文件命名**：文件名包含IP地址、频道数、上线时间、总体可用率数值
- **性能优化**：修复了VLC测试阻塞和程序卡顿问题
- **稳定性测试**：基于历史数据的智能文件筛选，自动保存最优文件
- **连通性测试**：智能抽样测试策略，最大测试8个频道，分组抽样验证
- **可用率测定**：基于抽样测试结果的总体可用率数值计算

## 安装指南

### 系统要求
- Python 3.8+
- Windows 10/11（推荐）或 Linux/macOS
- VLC播放器（可选，用于高级流媒体测试）

### 快速开始
```bash

git clone <repository-url>
cd iptv

# 创建虚拟环境
python -m venv .venv
.\.venv\Scripts\activate   # Windows
# source .venv/bin/activate  # Linux/macOS

pip install -r requirements.txt
```

- beautifulsoup4 >= 4.11.1
- pypinyin >= 0.50.0（中文拼音排序）
- tqdm >= 4.64.0（进度显示）

## 使用说明

#### 性能优化说明
程序已修复VLC测试导致的卡顿问题：
- 使用线程池进行并发测试，避免同步阻塞
- 限制最大测试频道数量为8个，避免资源竞争
- 添加超时控制机制，防止无限等待
- 简化异常处理逻辑，提高稳定性

#### 基本工作流程
```bash
# 完整流程：爬取 → 检测 → 优化 → 排序 → 稳定性测试
python main.py

# 仅执行M3U文件优化 + 稳定性测试（不爬取新数据）
python main.py --optimize-only

# 循环运行模式（例如运行3小时，间隔60分钟）
python main.py --hours 3 --interval 60
```

#### 稳定性测试功能
每次运行完成后，系统会自动执行稳定性测试：
- **测试所有M3U文件**：评估稳定性、在线时长、可用率、响应速度
- **智能筛选最优文件**：基于多维度评分算法选择最稳定的文件
- **自动保存最优文件**：保存为 `best_stable_channels.m3u` 固定文件名
- **历史数据记录**：SQLite数据库记录所有测试历史

#### 监控和调试
```bash
# 实时监控程序运行状态
python main.py --optimize-only

# 如果程序卡顿，使用Ctrl+C中断，然后检查日志文件
# 日志文件位于：output/logs/ 目录
```

### 输出文件说明
- `output/m3u/`: 优化后的M3U文件，按可用性和速度排序
- **最新文件名格式**：`[序号]地区信息_频道数ch_上线时间_总体可用率.m3u`
- **示例**：`[01]山西省太原市联通_40ch_今日上线_80.m3u`
- **格式说明**：
  - `[序号]`：排序序号，从01开始
  - `地区信息`：源IP地址对应的地理位置信息
  - `频道数ch`：该M3U文件包含的频道数量
  - `上线时间`：频道上线时间描述（今日上线、昨日上线、上线N天）
  - `总体可用率`：基于抽样测试的总体可用率数值（0-100，无百分号）

### 频道排序规则
1. **英文频道**：字母升序 + 自然数排序（1, 2, 10, 11）
2. **中文频道**：拼音升序 + 自然数排序
3. **混合频道**：数字优先，然后字母，最后中文

## 高级功能

### 自定义配置
修改 `config/constants.py` 中的参数：
- 并发线程数
- 超时设置
- 检测精度级别
- 排序规则偏好

### M3U优化器功能
- **自动可用性检测**：测试所有频道的连接状态
- **智能去重**：基于源IP地址去除重复文件
- **质量排序**：按可用率、速度和频道数量综合评分
- **文件重命名**：统一命名格式包含序号、地区信息、频道数、上线时间和总体可用率数值
- **详细日志记录**：记录优化过程和结果统计

### 稳定性测试系统
- **多维度评估**：稳定性评分、在线时长、可用率、响应速度
- **智能筛选算法**：综合评分公式，权重可配置
- **历史数据记录**：SQLite数据库存储完整测试记录
- **周期性监控**：可配置测试间隔时间
- **最优文件保存**：自动保存为固定文件名 `best_stable_channels.m3u`
- **数据驱动决策**：基于历史数据和实时测试结果选择最优文件

### 频道爬取机制说明
- **频道列表数量**：指每个IP地址对应的频道分类页面数量（如按地区、类型分类）
- **频道数量**：指每个频道列表页面中包含的具体电视频道数量
- **正常情况**：大多数IP只有1个频道列表页面，少数IP可能有多个分类页面
- **爬取流程**：程序会遍历所有频道列表页面获取完整的频道信息

### 连通性测试机制
- **智能抽样策略**：最大测试8个频道，避免资源浪费
- **分组抽样验证**：将频道分组，每组抽样测试代表性频道
- **可用率计算**：基于抽样测试结果计算总体可用率数值（0-100）
- **可用性判定**：严格的流媒体验证，包括响应状态、内容类型、数据读取验证

### 扩展开发
项目采用模块化设计，易于扩展：
- 新增爬虫：继承 `BaseCrawler` 类
- 自定义检测：实现新的测试器
- 排序算法：修改自然排序键函数
- 文件命名：自定义文件名格式
